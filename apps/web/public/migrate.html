Bring your progress with you.

Your quests, discoveries, compatible files, supported installed software and game records can continue in TuxOS. Keep your original download until you have checked the result.

1. Export where you played

Use the same browser and exact Tuxplore address you used before. Open its progress export page. If that page is not yet available, keep using Tuxplore and retain your browser data until the export bridge is published.

If you used a Tuxplore account, sign in there and confirm your latest progress has loaded before exporting. Tuxplore and TuxOS cannot read each other’s browser storage. HTTP and HTTPS addresses also have separate local storage. Never enter your old password into an import file.

2. Preview in TuxOS

  1. Open TuxOS and choose Explore TuxOS or resume your system.
  2. Choose Import & backups in the save controls.
  3. Select your downloaded JSON file, or paste a saved JSON backup. Review the file counts, history, compatibility notes and conflicts.
  4. Choose which preferences and in-progress adventure to keep. For each conflicting personal file, keep the current copy, use the imported copy, or keep both.
  5. Apply the import. TuxOS must save a recovery copy before replacing the current system.

3. Check and keep a backup

Open your personal files, adventure, discoveries, Pipe Dream and Know Your Distro. Older unlabelled runner scores appear as historical records; they are not assigned to Rapid or Infinite without evidence. Existing advanced Linux course completion is separate from the adventure.

Import reports explain unsupported fields and package differences. Download the report and original source. A repeat import does not award duplicate history. Oversized or damaged files are rejected with an explanation; your source file remains unchanged.

If you need to go back

Open Import & backups, select the recovery copy and preview its restoration. Restoring replaces the whole current simulated system and first backs it up again. Browser recovery copies are local: download them before clearing browser data. Importing a TuxOS backup is a whole-system restore, not a file merge.

Save to an account when ready

Choose Save to an account and authenticate to TuxOS. You can retain the account’s existing system or explicitly replace it with your browser system after a backup. A different username changes the home folder and ownership; personal text and command history stay unchanged. Matching usernames never links accounts automatically.

Keep Tuxplore available until real migrations have been checked. No retirement date is announced here. Report a problem without posting passwords, tokens or private file contents; share only a sanitized example when needed.
