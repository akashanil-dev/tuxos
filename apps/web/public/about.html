  • Continue into 34 Linux lessons and 150 checked tasks, Docker lessons, and a filesystem guide. Read instructions beside Files and Terminal, or switch to a focus view.

Start where you are

No account is needed to explore. Guest progress stays in this browser. Export a backup before clearing site data or changing devices. An optional TuxOS account saves your system across devices.

Vasu offers local hints without AI. AI assistance is optional and uses a provider and key you choose when the service supports it. This release adds no tracking to the migration or export flow.

TuxOS simulates Linux for learning. It does not install Linux, run arbitrary native programs, or change your computer’s files. The site still needs a connection to load; browser saves do not make it a fully offline app.
